# Soccer World Academy

Independent static website for team training and private soccer lessons at Lawrence Park, Indianapolis, IN. Players must bring their own soccer ball.

## Hosting

Serve this repository root as a static website. On Render use branch `main`, build command `echo "Static website ready"`, and publish directory `.`. No application secrets, database, package installation, OpenAI API, or ChatGPT login is required.

## Local use

Open `index.html` in a browser. Keep `globe-soccer-ball.webp` beside it. Fonts are loaded from Google Fonts, with system font fallbacks.

## Features

- Academy welcome, coaching background, team training, private lessons, experience pathways, location, equipment requirements, and FAQs.
- Training planner works entirely in the browser and does not submit personal information.
- Registration, bookings, payments, and user accounts are not enabled. Contact details, schedules, and prices still need to be supplied before booking opens.

Edit `index.html` to update the page. The image is a generated world globe with soccer-ball panels.
